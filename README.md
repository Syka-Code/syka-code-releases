## Qué bajar

| Tu equipo | Archivo |
| --- | --- |
| **Windows** (recomendado) | `Syka-Code-Setup-<versión>.exe`: se instala y **se actualiza sola** |
| Windows sin instalar | `Syka-Code-<versión>-portable.exe` (no se actualiza sola) |
| **Mac con Apple Silicon** (M1, M2, M3…) | `Syka-Code-<versión>-mac-arm64.dmg` |
| **Mac con Intel** | `Syka-Code-<versión>-mac-x64.dmg` |

## Al instalar

**Windows.** El instalador todavía no está firmado, así que Windows puede mostrar «Windows protegió tu PC». Toca **Más información → Ejecutar de todas formas**.

**macOS.** La app no está notarizada: la primera vez, clic derecho en `Syka Code.app` → **Abrir**. Si dice que está dañada, en Terminal:

```sh
xattr -dr com.apple.quarantine "/Applications/Syka Code.app"
```

## Actualizaciones

En Windows, con el instalador, Syka Code baja las versiones nuevas sola y te avisa con una tarjeta y sus novedades: se instalan al reiniciar. En macOS y en la portable te avisa y te lleva a la descarga.
